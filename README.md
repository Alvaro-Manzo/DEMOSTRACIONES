# DEMOSTRACIONES MATEMÁTICAS EN LATEX

Repositorio para la documentación y difusión de demostraciones matemáticas, redactadas en LaTeX con claridad, rigor y estilo profesional.

---

## Descripción

Este proyecto reúne una colección creciente de demostraciones matemáticas fundamentales y clásicas. Su objetivo es ofrecer material de consulta, apoyo al autoestudio y práctica de redacción matemática en LaTeX. El documento está dirigido tanto a estudiantes de nivel medio superior y superior, como a toda persona interesada en comprender la lógica formal detrás de teoremas clave en matemáticas.

## Compilación rápida

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/Alvaro-Manzo/DEMOSTRACIONES.git
   cd DEMOSTRACIONES
   ```
2. **Compila el archivo principal (`main.tex`):**
   ```bash
   pdflatex main.tex
   ```
   O usa plataformas como [Overleaf](https://www.overleaf.com/).
